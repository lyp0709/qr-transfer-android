# 本地二维码转译工具

完全离线的文件传输解决方案，通过本地网页和手机APP传输文件。

## 快速开始

### 1. 启动电脑端服务器

双击运行 `start.bat` 文件，服务器会自动启动。

浏览器会自动打开 http://localhost:5000

### 2. 传输文件

1. 在网页中拖拽或选择要传输的文件
2. 等待二维码生成
3. 用手机APP扫描二维码

### 3. 手机端接收

1. 安装Android APP（见下方说明）
2. 打开APP，授予相机权限
3. 依次扫描所有二维码
4. 点击"保存文件"

## Android APP 安装

### 方法1：使用Android Studio
1. 用Android Studio打开 `../android` 目录
2. 连接手机或启动模拟器
3. 点击运行按钮

### 方法2：直接安装APK
如果已有编译好的APK，直接安装到手机即可。

## 使用说明

### 电脑端
- **单个文件**：直接拖拽文件到网页
- **文件夹**：先压缩为zip，然后选择"文件夹"模式上传
- **大文件**：会自动分割为多个二维码，按顺序扫描

### 手机端
- **扫描**：确保二维码清晰可见
- **顺序**：按二维码编号顺序扫描（1/5, 2/5, 3/5...）
- **保存**：扫描完成后点击保存按钮

## 技术特点

- ✅ **完全离线**：无需网络连接
- ✅ **本地运行**：数据不经过外部服务器
- ✅ **简单易用**：拖拽上传，一键生成
- ✅ **安全可靠**：数据只在本地传输

## 故障排除

### 服务器无法启动
- 检查Python是否安装（需要Python 3.6+）
- 检查端口5000是否被占用
- 手动运行：`python app.py`

### 二维码无法扫描
- 确保二维码清晰完整
- 调整扫描距离和角度
- 检查光线条件

### 手机APP无法安装
- 确保允许安装未知来源应用
- 检查Android版本（需要7.0+）

## 文件位置

- **电脑端**：生成的二维码在 `generated_qr` 文件夹
- **手机端**：接收的文件在 `QRTransfer` 目录

## 卸载

删除整个 `qr-transfer` 文件夹即可完全卸载。
